# Get up and running with the POS API in under 5 minutes

## Base URL
- Development: `http://localhost:80/`

## Quick Overview
1. Create account → Get credentials
2. Authenticate → Get access token  
3. Make requests → Build your app

## Available endpoints
- `/dishes`: Manage menu items
- `/ingredients`: Manage ingredient inventory  
- `/users`: User management
- `/orders`: Order processing
